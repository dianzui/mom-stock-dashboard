# 妈妈的股票看板

一个给长辈看的 A 股每日看板：大字号、结论先行、每个数字都配一句大白话。

**在线地址**：https://dianzui.github.io/mom-stock-dashboard/

## 里面有什么

| 页签 | 内容 |
|---|---|
| ① 今天大盘 | 5 个主要指数、全市场涨跌家数、一句话情绪判断 |
| ② 超跌选股 | 近 5 日跌超 8% 且当天主力资金净流入、量比 > 1 的股票，按资金流入排序取前 5 |
| ③ 机构动向 | 最近一个月龙虎榜上榜次数最多的机构/营业部席位 |
| ④ 我的 24 只 | 自选股按「可以看看 / 再观察 / 建议回避」三档分组 |

## 自动更新

GitHub Actions 每个交易日 **北京时间 15:50** 自动运行：

1. `build.py` — 扫描全市场 5000 多只，算超跌 + 资金流，抓龙虎榜
2. `gather_watch.py` — 抓 24 只自选股的最新财报与资金流
3. `render.py` — 生成 `dashboard.html`，复制为 `index.html` 并提交

也可以在 Actions 页面点「Run workflow」手动触发。

## 数据来源

- 新浪财经：日 K、资金流趋势
- 腾讯财经：实时行情、前复权日 K
- 东方财富：龙虎榜、财务数据

全部为公开数据，不构成投资建议。

## 本地运行

```bash
python3 build.py          # 约 3 分钟
python3 gather_watch.py   # 约 1 分钟
python3 render.py         # 生成 dashboard.html
```

只依赖 Python 3 标准库，无需安装第三方包。
